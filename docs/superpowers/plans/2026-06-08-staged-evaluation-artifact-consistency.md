# Staged Evaluation Artifact Consistency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Execute the exact staged evaluation artifacts reviewed by the user and reject empty scenario runs.

**Architecture:** Extend the run request with optional typed stage artifacts, pass them through Redis unchanged, and let the engine use them instead of regenerating earlier stages. The staged React wizard submits its current valid TaskSpec, RubricSpec, and selected ScenarioSet, while quick evaluation remains unchanged.

**Tech Stack:** Python 3.12, FastAPI, Pydantic v2, Redis, pytest, React, TypeScript, Vite.
